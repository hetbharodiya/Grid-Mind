# Processed Energy Data Directory

## Purpose
This directory stores **cleaned, standardized, and hourly-aggregated** datasets generated by `app.services.data_preprocessor.DataPreprocessor`.

## Standardized Schema
All output CSVs in this folder conform strictly to:
- `timestamp`: ISO 8601 string representation (e.g. `2026-01-01 00:00:00`)
- `hour`: Integer (0–23)
- `day_of_week`: Integer (0=Monday, 6=Sunday)
- `energy_demand_kwh`: Validated, interpolated float value in kilowatt-hours

## Usage
Downstream Machine Learning feature engineering pipelines (Phase 3) will ingest files from this directory exclusively.
