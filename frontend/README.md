# GridMind AI — Frontend Application

## Overview
This directory will house the GridMind AI Operational Command Center frontend.

## Planned Technology Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Visualization**: Recharts (24-hour dispatch area charts, battery dynamics, KPI delta comparisons)
- **Icons**: Lucide React
- **API Client**: Axios

## Development Status
- **Current Phase**: Phase 2 (Foundation and Data Architecture)
- **Status**: *Intentionally deferred to Phase 5 per project roadmap.*
- **Implementation Plan**: Will be scaffolded with Vite and connected to FastAPI REST endpoints in Phase 5.
